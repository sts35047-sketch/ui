
# EPECT Atelier - Human Designer Edition (Never-seen UI)

This is the final atelier edition - tactile, editorial, human.

## Run
npm install
npm run dev

## Features
- Warm paper #fdf8f0 + noise texture, serif Newsreader + Inter
- File rail nav (Manila tabs with different heights, hand-drawn underline)
- Ink Stamp button (inner shadow press), paper clip, index cards with rotation
- Ledger book spread for attendance, thread of ink dots
- Quick Stack fanned cards
- Feedback as vertical handwritten timeline 01-02-03
- ID card pinned with tape

## Deploy
Push to Vercel - replaces ui-one-rosy.vercel.app

All views: desk (dashboard), cie, ledger (attendance), notes (feedback), id (profile)
Dark: deep ink #0f0e0c
Responsive: file rail -> bottom drawer
